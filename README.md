# MoviesClassification

A project for a machine learning course comparing different classifiers (Random Forest, Balanced Random Forest, XGBoost, CatBoost) on real-world data from the Letterboxd movie platform.

The goal is to predict the quality rating of a movie (e.g. Bad, Good, Masterpiece) based on features like popularity metrics, genre, language, studio, and director.

All steps — data preprocessing, exploration, modelling, and conclusions — are documented in `analysis.ipynb`.

[Letterboxd Movie Classification Dataset on Kaggle](https://www.kaggle.com/datasets/sahilislam007/letterbox-movie-classification-dataset?resource=download)
